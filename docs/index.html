AntiZapret → MikroTik OVPN RouterOS 7 · client-side

OpenVPN · сертификаты + .rsc

AntiZapret Генератор MikroTik OVPN

Вставьте свой *.ovpn, скачайте ca.crt / client.crt / client.key и готовый .rsc — импорт в терминале MikroTik.

Сертификаты и пароль не уходят на сервер: всё собирается в браузере. Целевая RouterOS 7.x. Маршруты AntiZapret приходят с сервера OpenVPN (reconnect после обновления списков).

1 Вставьте *.ovpn

Файл с сервера AntiZapret: antizapret-*-udp.ovpn или *-tcp.ovpn из /root/antizapret/client. «Разобрать» заполнит поля и извлечёт сертификаты.

2 Параметры

Протокол / схема IP

UDP → DNS шлюз 172.29.0.1 · TCP → 172.29.4.1. Порты AntiZapret: 50080 / 50443 (резерв 80, 443, 504, 508).

Режим DNS / VPN

Один туннель: DNS от OVPN (use-peer-dns=yes), On Up только flush кэша.

Из .ovpn
Сертификаты на MikroTik

После импорта файлов в Certificates укажите имя клиентского сертификата (часто client.crt_0). CA обычно помечается Trusted.

MikroTik

Тип подключения к провайдеру

Укажите интерфейс с DHCP. Скрипт выключит use-peer-dns у провайдера.

3 Сертификаты

После разбора .ovpn здесь появятся кнопки скачивания. Загрузите файлы в Files на MikroTik и выполните Import в System → Certificates.

4 Готовый .rsc

Заполните поля или вставьте *.ovpn…
  1. Скачайте ca.crt, client.crt, client.key и загрузите в Files
  2. Импортируйте сертификаты (System → Certificates → Import)
  3. Проверьте имя сертификата в поле выше (часто client.crt_0)
  4. Скачайте az-ovpn-ready.rsc и: /import file-name=az-ovpn-ready.rsc
  5. Маршруты подтянутся с сервера OpenVPN; после обновления AntiZapret — переподключите OVPN
